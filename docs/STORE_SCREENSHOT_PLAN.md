# Store screenshot plan

Capture real screens from a release/profile build at one consistent phone size. Do not composite features that are absent.

1. Home — greeting, today’s classes, upcoming tasks, academic overview.
2. Weekly schedule — a realistic multi-course day.
3. Attendance — percentage, requirement, status, and safe-miss/recovery explanation.
4. Tasks — active deadlines with different priorities and natural due labels.
5. Academic — GPA, attendance, credits, grades, and history navigation.
6. Notes and documents — searchable course-linked content.

## Safe manual demo-data procedure

Use an emulator/fresh debug installation. Enter a fictional Computer Science semester with Artificial Intelligence, Database Systems, and Software Engineering; use no real student identifiers. Add a few schedules, attendance entries, tasks, grades, notes, and one non-sensitive test PDF through normal UI. Capture screens, then use Delete all StudyMate data or uninstall. No demo fixture is compiled into production.

## Future feature graphic

Use the StudyMate mark, clean crops of real app screens, and one short practical value statement on a restrained academic-blue surface. Do not imply cloud, AI, authentication, or institutional endorsement.
