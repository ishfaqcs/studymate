# Play Console checklist

- [ ] Create or open the StudyMate app entry and confirm package `com.studymate.studentplanner`.
- [ ] Select the Education category.
- [ ] Complete the store listing using only implemented V1 functionality.
- [ ] Supply `DEVELOPER_SUPPORT_EMAIL_TODO` from the publisher.
- [ ] Publish the privacy policy and replace `PRIVACY_POLICY_URL_TODO` with its public HTTPS URL.
- [ ] Complete Data Safety from the verified release behavior and manifest.
- [ ] Declare that StudyMate contains no ads.
- [ ] Complete App access; StudyMate has no account or sign-in gate.
- [ ] Choose the intended target audience; publisher input is required.
- [ ] Complete the content-rating questionnaire; publisher input is required.
- [ ] Review the final release permissions in Play Console.
- [ ] Enable Play App Signing and retain the developer upload key securely.
- [ ] Create an Internal testing release before production.
- [ ] Upload the verified signed `StudyMate-1.0.0.aab`.
- [ ] Resolve all Play Console errors and review every warning.
- [ ] Install from the Play internal-test link and complete release QA.
- [ ] Promote to production only after Play-distributed QA passes.
