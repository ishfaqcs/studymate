## Full description

StudyMate is a local-first academic planner for organizing a semester. Keep courses, weekly classes, rooms, attendance, assignments, quizzes, exams, notes, documents, grades, GPA, and academic history together. Optional local reminders help with deadlines. Create validated local backups and a personal PDF academic summary when needed.

StudyMate V1 has no accounts, ads, analytics, AI, subscriptions, or cloud synchronization.
