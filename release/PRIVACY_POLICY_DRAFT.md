# StudyMate privacy policy publication draft

Replace `DEVELOPER_SUPPORT_EMAIL_TODO`, add an effective date, obtain appropriate review, and host this policy at a public HTTPS URL before release. Replace `PRIVACY_POLICY_URL_TODO` in the store listing only after publication.

StudyMate stores the profile, semester, course, schedule, attendance, task, grade, note, preference, reminder, and imported-document information entered or selected by the user. Imported documents are copied into app-private storage. StudyMate V1 has no account, advertising, analytics, AI, or cloud synchronization; core academic data is processed locally.

The Android system picker grants access only to user-selected files. Notification permission supports optional reminders. User-created backups and PDFs leave private storage only through a user-selected save, print, or share destination. External applications and providers then govern those copies.

Users can delete individual records or use Data & Backup > Delete all StudyMate data. Uninstalling removes app-private data subject to Android backup/device behavior. Users must separately delete exported files.
